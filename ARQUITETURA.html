📁 Arquivos Principais

index.html - Menu com links para 4 aplicações
supabase-client.js - Cliente para conectar ao banco
vercel.json - Configuração de deploy
.env.example - Variáveis de ambiente
SETUP_VERCEL_SUPABASE.md - Guia completo

🚀 Setup Supabase

  • Criar conta em supabase.com
  • Criar novo projeto
  • Copiar URL e chave ANON
  • Executar scripts SQL de tabelas
  • Ativar Row Level Security
  • Copiar credenciais para .env.local

🌐 Deploy Vercel

  • Inicializar Git no projeto
  • Push para GitHub
  • Conectar repositório no Vercel
  • Adicionar env vars no Vercel
  • Fazer deploy
  • Testar no domínio vercel

💾 Integração de Dados

  • Incluir supabase-client.js nos HTMLs
  • Trocar localStorage por Supabase
  • Adicionar sincronização automática
  • Implementar backup
  • Testar CRUD (Create, Read, Update, Delete)
  • Validar persistência

🔐 Segurança

  • Nunca commitar .env
  • Usar variáveis de ambiente
  • Ativar CORS no Supabase
  • Implementar Row Level Security
  • Validar entrada de dados
  • Usar chave ANON para cliente

⚡ Quick Start

1️⃣ Local (desenvolvimento)

cd c:\Python_App\AppFinIA
python -m http.server 3000
# Abrir: http://localhost:3000

2️⃣ Git + GitHub

git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/usuario/appfinia.git
git push -u origin main

3️⃣ Vercel Deploy

1. Acesse: vercel.com
2. Clique: Add New → Project
3. Selecione: seu repositório no GitHub
4. Adicione: Environment Variables
5. Deploy! 🚀

4️⃣ Usar Supabase nos HTMLs

<script src="supabase-client.js"></script>

// Inserir dado
await window.db.insert('receitas', {
  descricao: 'Salário',
  valor: 5000,
  mes: '2025-05'
});
